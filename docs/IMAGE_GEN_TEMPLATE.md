# Desktop Pet 이미지 생성 템플릿

이 문서는 캐릭터 레퍼런스를 바탕으로 Desktop Pet용 PNG 프레임을 만들 때 사용하는 공통 규칙과 프롬프트 예시다.

목표는 생성된 PNG를 `assets/characters/<캐릭터 이름>/<모션>/`에 넣으면 추가 코드 수정 없이 사용할 수 있게 하는 것이다.

## 공통 규칙

모든 모션 생성 요청에 아래 조건을 공통으로 넣는 것을 권장한다.

```text
- 투명 배경 PNG
- 모든 프레임 동일한 캔버스 크기
- 캐릭터의 크기와 중심 위치를 일관되게 유지
- 발이 닿는 바닥 기준선을 프레임마다 최대한 동일하게 유지
- 캐릭터 전신이 프레임 밖으로 잘리지 않게
- 배경, UI, 텍스트 없음
- 바닥 그림자와 광원 효과는 최소화
- 프레임마다 복장, 머리카락, 색감, 얼굴, 비율이 바뀌지 않게
- 움직임에 필요한 부분만 변화
- Desktop Pet에서 바로 사용할 수 있는 스프라이트 프레임
```

가능하면 먼저 기준이 될 `idle/0001.png`를 만든 뒤, 이후 모션 생성 때 그 이미지를 레퍼런스로 다시 제공하는 편이 프레임 일관성을 유지하기 쉽다.

한 장의 작업용 스프라이트시트로 제작한 경우에는 완성 후 각 칸을 같은 크기의 투명 PNG로 추출한다. 현재 엔진은 스프라이트시트를 직접 읽지 않는다. 생성 과정의 원본 파일과 실행용 PNG를 구분해 보관한다.

## idle

```text
내가 제공한 캐릭터 레퍼런스를 기준으로 Desktop Pet용 idle 애니메이션 프레임 6장을 만들어줘.

조건:
- 투명 배경 PNG
- 모든 프레임의 캔버스 크기 동일
- 캐릭터 크기와 위치 동일
- 전신이 프레임 안에 들어오게
- 살짝 숨 쉬거나 머리카락과 옷이 미세하게 움직이는 정도의 idle 모션
- 첫 프레임과 마지막 프레임이 자연스럽게 이어지는 루프
- 캐릭터의 복장, 머리카락, 색감, 얼굴, 비율을 레퍼런스와 최대한 일치
- 배경 없음
- 그림자 최소화
- 각 프레임을 독립된 PNG로 사용할 수 있게 구성
```

권장 파일명:

```text
idle/
├─ 0001.png
├─ 0002.png
├─ 0003.png
├─ 0004.png
├─ 0005.png
└─ 0006.png
```

## walk

```text
내가 제공한 캐릭터 레퍼런스를 기준으로 Desktop Pet용 walk 애니메이션 프레임 8장을 만들어줘.

조건:
- 투명 배경 PNG
- 모든 프레임 동일 캔버스
- 자연스럽게 반복되는 걷기 한 사이클
- 프레임마다 발이 닿는 지면 기준선이 크게 흔들리지 않게
- 몸 전체 위치가 불필요하게 좌우로 이동하지 않게
- 전신 유지
- 스타일, 얼굴, 의상, 비율, 색상 일관성 유지
- 배경과 텍스트 없음
- 각 프레임을 독립된 PNG로 사용할 수 있게 구성
```

권장 파일명:

```text
walk/
├─ 0001.png
├─ 0002.png
├─ ...
└─ 0008.png
```

## dragged

```text
내가 제공한 캐릭터 레퍼런스를 기준으로 Desktop Pet에서 마우스로 잡혔을 때 사용할 dragged 상태 이미지 1~2장을 만들어줘.

조건:
- 투명 배경 PNG
- 몸이 바닥에서 살짝 들린 느낌
- 잡혀 있다는 것이 표정이나 자세에서 자연스럽게 보이게
- 원래 캐릭터의 얼굴, 복장, 비율, 색상 유지
- 전신이 잘리지 않게
- 배경과 텍스트 없음
```

## happy

```text
내가 제공한 캐릭터 레퍼런스를 기준으로 Desktop Pet의 클릭 반응용 happy 애니메이션 프레임 4~6장을 만들어줘.

조건:
- 투명 배경 PNG
- 짧게 기뻐하거나 반응하는 동작
- 시작 자세와 종료 자세가 idle로 자연스럽게 이어질 수 있게
- 전신 유지
- 캐릭터 디자인 일관성 유지
- 배경과 텍스트 없음
```

## look

```text
내가 제공한 캐릭터 레퍼런스를 기준으로 Desktop Pet의 look 애니메이션 프레임 4~6장을 만들어줘.

조건:
- 투명 배경 PNG
- 고개나 시선을 살짝 돌려 주변을 보는 짧은 동작
- 과도한 전신 이동 없이 제자리에서 반응
- 시작과 끝이 idle 자세와 자연스럽게 연결
- 캐릭터 디자인 일관성 유지
- 배경과 텍스트 없음
```

## 생성 후 확인 체크

이미지를 폴더에 넣기 전에 다음만 확인한다.

- 모든 프레임 해상도가 같은가
- 투명 배경인가
- 캐릭터가 프레임 밖으로 잘리지 않았는가
- 발의 기준선이 지나치게 흔들리지 않는가
- 캐릭터 크기가 프레임마다 달라지지 않는가
- 파일명이 `0001.png` 형식으로 정렬 가능한가
- idle 폴더에 최소 1장의 PNG가 있는가

최소한 `idle/0001.png`만 준비되면 캐릭터 팩은 실행 가능하다.
